# 质量闸门

## Gate A：脚本批准

必须同时审查：

- 原著来源和覆盖度；
- 事实、引语和现代解释的边界；
- 三条叙事路线与选择理由；
- 命运锚点和事件卡；
- Performance、Release、Audit 三版稿；
- 零上下文盲审；
- Release 稿零标签泄漏。

批准绑定文件 Hash。文本变化后，下游音频和画面全部失效。

## Gate B：视觉锚点与 LookDev

必须同时审查：

- 本书专属视觉 Profile；
- 主角、配角、场景和物件锚点；
- 12 张 LookDev 联系表；
- 人物身份、时代、材质、光线和景别；
- 与参考样本共享质量底座，但不复制特定创作者资产；
- 高风险镜头全部规划为单图。

机器亮度和饱和度只能提示风险，不能宣布审美通过。

## Gate C：最终母版

自动硬门禁：

- 1920×1080、30 fps、H.264、yuv420p；
- AAC、48 kHz；
- 音视频流完整；
- 时长与主音频一致；
- 无异常长黑帧和静音；
- 字幕在安全区；
- 开头快闪和选中卡有可测运动；
- 旁白、字幕、图片共享 Beat；
- BGM 可闻但不压旁白。

人工/多模态抽查：

- 每章首帧；
- 全部高风险镜头；
- 高潮、理论段和结尾；
- 随机镜头；
- 人物、手部、道具、时代和语义一致性。

只有最终编码 MP4 的 `local_master_review` 批准后才能发布。
