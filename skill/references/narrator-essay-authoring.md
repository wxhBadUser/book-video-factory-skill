# Narrator-Essay 口播稿写作手册（v2，手艺标准）

> 本文件是 `cinematic-narrator-essay-v1` 生产线的**写作手艺规范**，与既有指标门禁（字数/时长/中段位/理论占比/AI排比等）互补：**指标管"及格"，本手册管"好听"**。
> 适用：单主播电影化名著口播稿（85%–95% 主播声 + 5%–15% 短引文/对白，无独立角色配音线）。
> 触发：写稿 / 改稿 / 审稿前**必须**通读本文件。
> 红线：本手册只编码**结构 / 语域 / 节奏**等可复用手艺。**严禁复制**任何参考创作者的固定话术、比喻、口头禅、声音身份——改进的是"方法"，不是"某人的声音"。

---

## 1. 一句话定位

不是"书评"，是"**一个有趣的人，在你耳边聊他刚读完的一本书**"。
观众 retention 不靠信息密度，靠**被一个人带着走**：有钩子、有破绽、有反事实、有转向"你"的时刻、最后把书种进他的人生。

---

## 2. 声音守则（Voice）

- **标签是工程标记，不是人声内容**：`【hook / narrative / reaction / theory / ending / midpoint】` 等结构标记**写进表演版每一行的行首**（canonical 核验器要靠 `【theory】/【midpoint】` 算占比，TTS 要靠它做 cueing，都必需），但**标签之后的念白必须是纯净口语散文**，标签本身不会进入观众耳朵（它只是 cue，TTS 会忽略或剥离）。真正 100% 无标签的是 **RELEASE 文件**（去标签，已验证 leak=0）。**判干净的标准 = release 文件零标签泄漏，不是 performance 零标签**——上版手册写"表演版零标签"是错话，已更正。
- **聊天的松弛 > 讲稿的工整**：金标准魅力来自"闲扯声线"——短句、自嘲、绕一点、偶尔跑题再拉回。别把每句都写成"论点句"，理论段尤其要像"我边想边说"，不是"讲义"。字数帽紧时，宁可删一个论点，也要留住一句人话。
- **一个主播人格**：贯穿全片用同一个"我"。允许 pace / pause / emphasis / energy / warmth / restraint / intimacy / irony / grief / wonder 随书变化，但**人格不变**（不切换成另一个人）。
- **口语但不口水**：短句、口语连词（"说真的""你想啊""话不多说"类——但要用你自己的，不抄样本原句）、适度破绽（"这问题我没答案""我读时愣了很久"）。
- **脆弱 > 笃定**：允许 1–2 处坦诚"我没想明白 / 我替他着急 / 这事儿没答案"。全片笃定 = 像 AI。
- **第二人称植入**：结尾前必须有对"你"的直接问句（见 §4-7）。

## 3. 八幕结构（每幕的"主播动作"必须齐）

| 幕 | 必做动作 | 缺了会怎样 |
|---|---|---|
| **O 开场** | **【第 0 件】读者痛点 / 系列价值**（"想都知道名著好，但名著太难读了"式——先卖"为什么要有这个系列"）→ 系列框架（系列名+本期序号+为什么是这本）→ "特别"钩子（同品类的唯一性）→ 社会证明（借读者原话，不自查）→ 中心问句 → 转场 | 没人知道"为什么听你讲" |
| **A 立锚** | 点出**一个可视象征对位**（如双庄园=双活法），**开头就立**，结尾回扣 | 全片没有脊梁，散 |
| **B 起势** | 人物出场 + **1 处名字词源/含义拆解当命运伏笔** + 具象比喻群画关系 | 人物是符号不是人 |
| **C 转折** | 关键岔路 + **织入原著原声**（2–4 句最锋利的金句，当角色本人在说话）+ **第 1 个反事实钩子** | 故事平、没有参与感 |
| **D/E 复仇/深渊** | 机制点破（恶/体制的逻辑，而不只是"他坏"）+ **第 2 个反事实钩子** | 反派脸谱化 |
| **F 收束** | 用**画面+原声**收，不总结；让情绪悬着 | 结尾像念稿 |
| **G 解法** | **抛中心谜题 → 理论作为谜底自然长出**（用大白话，不标"理论"）→ 时代/结构点破 → **转向观众**（第二人称"你有没有过…"） → **反鸡汤收尾**（拒绝"忠于自己"式正确废话） | 理论是板块、结尾是鸡汤 |
| **H 落版** | 反鸡汤收束 + **"我是[人设名]，感谢…下期见"** + 系列钩子 | 没有人格签名，不留追更入口 |

---

## 4. 六大必装"钩子零件"

0. **读者痛点 / 系列价值（hook 第 0 件）**：开场第一句就戳"读者为什么需要这个系列 / 为什么这本名著难读"——金标准首句即痛点。先卖价值，再给框架。
1. **系列框架**：开场 1–2 句给"这是 X 系列第 N 本 / 我们今年读 Y 本"，制造追更理由。
2. **反事实插入（1–2 处）**：关键岔路口插"如果当时他多等/多说一句，结局会不会不一样？"——最强参与装置。样本用 2 次，本手册要求 ≥1。
3. **转向观众**：结尾前 1 段必须是**直接对"你"的问句**，把书种进观众自己的人生（"你有没有过…明明很对，却因为它不够体面压了下去？"）。
4. **人设落版**：结尾固定"我是[人设名]，感谢你的点赞与关注，下期见"——短、暖、有签名感。
5. **象征锚早立晚收**：每本提炼 1 个可视对位，A 幕立、H 幕扣。
6. **名字当武器**：每本 1 处关键名（人/书/地名）词源或含义拆解，作命运伏笔。

---

## 5. 理论怎么写（最易翻车处）

- **先有谜题，后有理论**：G 幕先抛"究竟被谁毁掉 / 他到底被什么杀死"，再用理论当谜底。
- **用主播自己的话讲**，大白话，可引用但不堆术语。行首 `【theory】` 工程标签**允许且必需**（canonical 核验器靠它算理论占比）；**禁止的是**"下面我们来讲讲理论"式生硬切入、或语气突然变"老师上课"。理论要像从故事里长出来的，不是另起一段公告。
- **理论占比**仍受指标门禁约束（通常 8%–12%），但那是字数，不是"单独成段"的借口——理论应化进叙事流。
- **反鸡汤优先**：收尾拒绝"做自己""忠于内心"式正确废话；给"你选了哪个、放下了哪个"的清醒。
- **反应多暴露自己，少点破机制**：金标准的"真人反应"常是"我也想不通 / 我替他着急 / 这事儿没答案"，不是"看，这里作者用了 X 手法"。每本书 5–8 处反应里，至少 3 处要是"暴露主播自己的迟疑 / 自嘲 / 代入"，而非"解析书里机制"。

---

## 6. 引文怎么织（不得只躺审计 JSON）

- 选 **2–4 句**最锋利原著原声（或权威译本口播化翻译，见引文审计规范）。
- 织入方式：引文**当角色/作者本人在说话**，前后用主播的话接住（"他说……""这句话我读了很多遍"）。
- 表演版可直接出现引文文字；标签（F/Q/A/I/E 等）只在审计版标注。

---

## 7. 速率契约（沿用 SKILL.md，复述备查）

平均 250–280 / 钩子 280–315 / 叙事 255–285 / 告白·死亡·重解读 225–260 / 理论 245–275 / 尾句 220–245 字/分钟。
钩子节奏来自**短句 + 密集切句**，不是全片狂飙。

---

## 8. 禁区（Forbidden）

- ❌ **把标签意思念出声**：标签（行首 `【…】`）是工程标记，可存在于表演版；但**念白正文必须是纯净口语**，不得出现"下面我们进入理论板块"这类把标签语义说出来的跳变。（RELEASE 文件则连行首标签都不得出现，leak 必须 = 0。）
- ❌ "【reaction： 真人反应N】" 这类模板占位；反应须第一人称、带脆弱、融进叙事流。
- ❌ 理论以"下面讲理论""我们来总结一下"式生硬切入或语气跳变为"讲课腔"（行首 `【theory】` 标签本身允许）。
- ❌ 通用鸡汤收尾（"我们要勇敢做自己""读书使人成长"类）。
- ❌ 复制参考创作者的固定话术/比喻/口头禅/声音身份（内容安全硬红线）。
- ❌ 无系列框架、无反事实、无转向观众、无人设落版四件套缺任一项（属"手艺不及格"）。

---

## 8.5 范本级门禁（v1.2，实证测试补强）

实证测试证明：**指标全过 ≠ 范本级**。旧稿可能 15 项 67/75 压线、反例库不触发，但仍不是观众会听下去的口播稿。以下四条是"及格"之上"像金标准"的硬要求，对应四个校验器（`narrator-essay.click-question-sharp / midpoint-emergent / theory-anchored / ending-takeaway`），任一不过即打回。

### G1 点击问题必须锋利（点击问题 ≠ 阅读痛点）
- 开头 15% 必须有一个**当代可辩论的"命运问句"**（"为什么/到底/凭什么/该不该/值不值得/图什么"），观众能当场站队。
- 禁止只停在**阅读痛点**（"名著难读""读两页合上"）——那是开场引子，不是点击问题。
- 反例对比：`"理想和责任到底选哪个？"`（范本《六便士》）✅；`"名著太难读了"` ❌。

### G2 中点必须从结构涌现（中点 ≠ 挪位）
- 中点（40%–55%）必须出现一个**新问句**，且**不得照抄开头问句**。
- 这个新问句必须带着**升级标记**：外部障碍消失/已成功却更不满足/人物已死冲突才开始（"明明…为什么/已经…却/赢了…可/死后…才"）。
- 禁止为过 55% 区间而机械挪位——中点要长在故事结构上（如窄门"障碍全清空了，她还在躲什么"）。
- 反例对比：`"明明赢了，可赢到手不等于结束"`（升级）✅；把开头问句原样搬到中段 ❌。

### G3 理论必须锚定本书（理论 ≠ 通用鸡汤）
- 理论段（后 30%）必须出现**本书独有的主象征词**（primary_metaphor，如"大海""月亮/六便士""窄门""庄园/窗"）。
- 禁止纯通用概念硬贴（"输 vs 被打败"若不带"大海"这类本书意象即打回）。
- 范本《六便士》理论锚定"月亮/六便士"书名象征，不是裸讲"自性化"。

### G4 结尾必须给可带走框架（结尾 ≠ 情绪反问）
- 结尾（最后 10%）必须**对"你"说话 + 给一个可行动的框架**（"白天…夜晚…/手中有X心中有Y/不必…可以…"）。
- 禁止只停在开放式反问（"你的那片海还在吗"）——那有情绪但没给观众可带走的东西。
- 禁止通用鸡汤（"勇敢做自己/热爱生活"）且无本书意象。
- 范本《六便士》结尾：`"手中有六便士，去应付生活的苟且；心中有月亮，去抵御岁月的漫长"`。

### G5 对抗性审查门（写完后必须过）
- 三版本稿完成后，**强制**跑一轮零上下文对抗审查：独立子 agent 用 15 项评分表 + 反例库审稿。
- 门槛：**总分 ≥ 72**（高于现有 66 及格线），且 G1-G4 对应的 4 项（点击问题/中点/现代解释边界/结尾专属性）**任一项 ≥ 4**，事实可靠性 = 5。
- < 72 或任一项 < 4 → 按审查意见修订后重审。打回理由必须落到"范本级"（锋利/涌现/专属/框架），不是"指标差"。

## 10. 与现有门禁的关系

- **指标门禁**（`verify_script_metrics.py` / `check_*`）：管字数、时长、中段位、理论占比、现代映射字数、主角入场、真人反应数、AI 排比数。本手册不替代它们，是在其之上加"手艺层"。
- **审计版**：保留 F/Q/A/I/E + 结构标签 + 时间码，供剪辑/配音/校验；与表演版同源生成，表演版 = 审计版去标签。
- **锁稿门禁 JSON 必须如实上报**：`performance_prose_contains_structural_tags = true`（预期，因工程标记）、`release_tag_leak = 0`（必须）。**严禁**把 performance 谎报为"零标签"——那是把工程格式当人声干净的假象，会误导下游与人工审稿。
- **引文审计**：短引语按 `quote_translation_audit.json` 标注来源（权威译本 / 口播化翻译 / 转述 / 原创阐释）；未指定权威译本时标"原文口播化翻译"。
