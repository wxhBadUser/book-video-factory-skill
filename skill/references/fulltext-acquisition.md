# 中文全文获取规范（文案引擎 v2 · 第一步）

> 目的：任何一本书进入写稿前，必须有一份**顺序可靠、可逐字核验**的中文全文落盘。没有全文 = 阻塞，禁止凭模型记忆开写。
> 实证：六书金标准全文（天涯书库/小鸭子儿童乐园）+《活着》全文（麦田繁体 EPUB→简体化），见 `docs/reference_cases/fulltext/`。

## 1. 来源选择（按优先级）

1. **EPUB/电子书文件**：优先。顺序最可靠，无站点水印。下载后先验证 ZIP 魔数（`PK`），再按 spine 顺序解包提取（Python `zipfile` + OPF spine）。
2. **免费在线阅读站**：天涯书库（GBK，`book/<slug>/` 目录 + `<id>.html` 章节）、小鸭子儿童乐园（UTF-8）等。必须显式按页面 charset 解码（GBK 用 `Encoding.GetEncoding(936)`），禁止乱码入库。
3. **书库镜像/备用源**：主源被墙/403 时，换 curl `-k` + 浏览器 UA，或 open_page（网络栈不同）。微信文章/掌阅等需 APP/JS 渲染的源不可程序化抓取时放弃。

## 2. 抓取与落盘规范

每本书一个目录，固定结构：

```text
docs/reference_cases/fulltext/<SLUG>/
  chapters/01_第X章.txt ...        # 逐章干净文本（每章第一行=章节名）
  全文.txt                          # 合并全文（含章节分隔头）
  SOURCE.md                         # 来源声明（见下）
```

- 章节文件与 `全文.txt` 均 UTF-8 写入。
- 章节命名：`<NN>_<章节名>.txt`，按书实际分卷/分章；原书无章节（如《活着》）以来源站切分为准并注明。
- `SOURCE.md` 必须含：书名/作者/抓取日期/来源 URL/站点性质/编码/章节数/全文文件路径/SHA-256/字节数/**版权说明**（受版权保护作品仅作内部拆解对照，不得出版传播；正式引用购正版）。

## 3. 质量门禁（抓完必须过）

1. **无乱码**：全文无 U+FFFD；无残留 HTML 标签/实体。
2. **无站点水印**：扫描常见水印词（如"九九藏书网/藏书网/九_九_藏_书_网"）并从正文清除；清完再扫一次归零。
3. **顺序可靠（最重要）**：抽样验证叙事连续性——章节开头/结尾、关键事件先后是否正常。**警惕站点打乱段落**：九九藏书网镜像的《活着》正文段落被随机打乱（"福贵开始讲述"后竟接结尾对话），必须用"关键事件顺序抽查"检测。乱序处理：
   - 换用 EPUB 底本重建（最可靠）；
   - 或以已核验的 EPUB/纸质版逐段重排；
   - 在 SOURCE.md 记录弃用原因，不保留乱序版作底本。
4. **文本规范化**：繁体 EPUB → 简体（OpenCC t2s），并手动收尾：`著→着`（白名单：编著/著作等）、`牠→它`、`執著→执着`；处理后再全量验证关键金句存在。
5. **跨源补缺**：某版本缺句（如九九版缺"福贵，我是替你去死啊"）时，用多源一致的通行版本补入，并在 SOURCE.md 记录补丁。

## 4. 引语核验基准

- 全文落盘后，写稿阶段所有引语以 `全文.txt` 为唯一逐字基准（连续子串匹配）。
- 译本差异（如思特里克兰德/斯特里克兰、所活着/而活着）以底本为准，并在引用审计中注明。
- 每本书产出一份 `07_<书名>_全文到口播拆解.md`（见 script-workflow-v2.md 第 2 步），其中全部引文必须可检索验证。
